# PortfoliAI Coach Client

React/Vite frontend voor PortfoliAI Coach.

## Starten

```bash
npm install
npm run dev for server and client.
```

De frontend verwacht standaard dat de backend draait op `http://localhost:3001`.

Wil je een andere backend URL gebruiken, maak dan een `.env` in de map `client`:

```env
VITE_API_URL=http://localhost:3001
```
